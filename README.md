🚀 MLOps Production Pipeline: Restaurant Rating & Recommendation System
Промышленный пайплайн машинного обучения для анализа данных ресторанов, прогнозирования рейтингов с помощью ансамблей деревьев и деплоя модели в виде FastAPI-микросервиса.
📌 Описание проекта
Проект состоит из четырех основных задач уровня ML/MLOps инженера:
Task 1: Предсказание совокупных рейтингов ресторанов (регрессия) с очисткой выбросов (IQR) и тестированием моделей XGBoost / HistGradientBoosting.
Task 2: Построение рекомендательной системы на основе косинусного сходства (Cosine Similarity) и кластеризации K-Means.
Task 3: Классификация кухонь ресторанов и борьба с дисбалансом классов.
Task 4: Геоаналитика и поиск популярных зон (кластеризация DBSCAN).

⚙️ Как запустить проект
Установи зависимости: pip install -r requirements.txt
Запусти API через Docker или Uvicorn.
